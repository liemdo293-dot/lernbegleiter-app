# Lernbegleiter

Eine Lern-App für die Oberstufe: Stundenplan, Hausaufgaben, Klausuren, Noten, Lern-Timer, Statistik und ein KI-Quiz.

**App öffnen:** https://liemdo293-dot.github.io/lernbegleiter-app/

## Funktionen

- **Heute:** laufende Stunde live und ein Tagesplan für den Nachmittag
- **Woche:** der eigene Stundenplan
- **Aufgaben:** Hausaufgaben mit Fälligkeit „nächste Stunde“
- **Klausuren:** Countdown und automatische Lernblöcke
- **Fächer:** Noten von 0 bis 15 Punkten, Schnitt pro Fach
- **Fokus:** Lernzeit am Stück mit großem Timer – auf dem iPhone sperrt sie auf Wunsch ablenkende Apps (über die Kurzbefehle-App, Anleitung in der App)
- **Lern-Timer, Statistik und KI-Quiz**

## Datenschutz

Die App enthält keine persönlichen Daten. Stundenplan, Hausaufgaben und Noten werden **nur im Browser des eigenen Geräts** gespeichert und nie an einen Server geschickt. Zum Übertragen zwischen Geräten gibt es in den Einstellungen „Daten sichern“ und „Wiederherstellen“.

## Auf dem iPhone installieren

1. Den Link oben in **Safari** öffnen
2. Unten auf **Teilen** tippen und **„Zum Home-Bildschirm“** wählen
3. Die App vom Home-Bildschirm aus starten und dort den Stundenplan laden

## Technik

Reines HTML, CSS und JavaScript ohne Framework. Funktioniert offline.
